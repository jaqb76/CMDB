Przywróć z kopii

Przywrócenie zastępuje całą bazę wszystkich firm oraz pliki zgłoszeń i wydań agenta. Zrzut Postgresa nie jest biernym plikiem z danymi — przy odtwarzaniu wykonuje SQL jako właściciel bazy. Dlatego pytam o hasło jeszcze raz, mimo że jesteś zalogowany.

Wgrane archiwum musi mieć manifest zapisany przez ten system — plik sprzed roku albo ucięty transfer zostanie odrzucony. Formularz przyjmuje do {{ limit_wgrania | bytes }}; przy większej kopii skopiuj ją przez scp i użyj python -m cmdb_server.cli przywroc.
