Wersje agentow

Agent jest osobnym plikiem dla kazdego systemu operacyjnego.

Trzy poziomy, od najwezszego: ustawienie na maszynie → ustawienie firmy → wersja oficjalna. Dzieki temu mozna trzymac wersje probna w jednej organizacji, podczas gdy pozostale pracuja na wersji oficjalnej. Serwer niczego nie wysyla — agent sam sprawdza oczekiwana wersje przed swoja synchronizacja i sam pobiera plik.
