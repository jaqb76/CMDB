Agent dla Linuksa

Na Linuksie agent jest wydawany jako paczka źródeł, nie plik wykonywalny: PyInstaller nie kompiluje na inna architekturę, więc jeden plik nie obsłużyłby zarazem serwerow x86 i Raspberry Pi. Jedna paczka działa na każdej architekturze, bo agent stoi na samej bibliotece standardowej Pythona.

Paczka jest zwyklym wydaniem — widać ja niżej z architektura źródła, ustawia się ja jako aktywna i przypisuje firmom tak samo jak plik dla Windows. Aktualizacja polega na podmianie katalogu /opt/cmdb-agent: agent pobiera paczke, sprawdza jej skrót, uruchamia nowa wersje probnie i cofa zmianę, gdy ta nie wstaje.

{% if import_enabled %}

Paczki Linux pochodzą z tego samego przetestowanego wydania CI co agent Windows. Ich wersje i stan dopuszczenia są widoczne w katalogu poniżej. Instalacja nowej maszyny po wybraniu wersji: curl -fsSL <adres>/download/install.sh | sudo bash -s -- --token ...

{% elif paczka_zrodel %}

Serwer zbudował paczke w wersji {{ paczka_zrodel.version }} i wpisał ja do magazynu wydan. Instalacja nowej maszyny: curl -fsSL <adres>/download/install.sh | sudo bash -s -- --token ...

{% else %}
Serwer nie zbudował paczki źródeł. Buduje się ja poleceniem python -m cmdb_server.pakiet ../agent, można też wgrać gotowa ponizej.
{% endif %}
