Agent dla Linuksa

Na Linuksie agent jest wydawany jako paczka zrodel, nie plik wykonywalny: PyInstaller nie kompiluje na inna architekture, wiec jeden plik nie obsluzylby zarazem serwerow x86 i Raspberry Pi. Jedna paczka dziala na kazdej architekturze, bo agent stoi na samej bibliotece standardowej Pythona.

Paczka jest zwyklym wydaniem — widac ja nizej z architektura zrodla, ustawia sie ja jako aktywna i przypisuje firmom tak samo jak plik dla Windows. Aktualizacja polega na podmianie katalogu /opt/cmdb-agent: agent pobiera paczke, sprawdza jej skrot, uruchamia nowa wersje probnie i cofa zmiane, gdy ta nie wstaje.

{% if paczka_zrodel %}

Serwer zbudowal paczke w wersji {{ paczka_zrodel.version }} i wpisal ja do magazynu wydan. Instalacja nowej maszyny: curl -fsSL <adres>/download/install.sh | sudo bash -s -- --token ...

{% else %}
Serwer nie zbudowal paczki zrodel. Buduje sie ja poleceniem python -m cmdb_server.pakiet ../agent, mozna tez wgrac gotowa ponizej.
{% endif %}
