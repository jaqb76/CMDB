Instalacja agenta

Gotowe polecenia dla nowych maszyn w firmie {{ ctx.tenant_name }}.

Wszystkie polecenia wymagaja tokenu rejestracyjnego tej firmy. Jest jeden na cala organizacje — ten sam wpisuje sie na kazdej maszynie. Nie mozemy go tu wypisac, bo w bazie trzymamy wylacznie jego skrot; wartosc jawna pokazywana jest raz, przy wydaniu. Masz go pod reka? Wklej zamiast TWOJ_TOKEN. Jesli nie — wygeneruj nowy.

Linux (Ubuntu, Debian, Raspberry Pi)

{% if paczka_linux %}

Jedno polecenie na maszynie docelowej — nie trzeba niczego klonowac ani budowac: 

curl -fsSL {{ adres_serwera }}/download/install.sh \
  | sudo bash -s -- --token TWOJ_TOKEN

Skrypt pobiera z tego serwera zrodla agenta, sprawdza ich skrot SHA-256, zaklada usluge i timer systemd oraz wysyla pierwszy raport. Agent stoi na samej bibliotece standardowej Pythona, wiec dziala na kazdej architekturze — takze na ARM, gdzie gotowy plik zbudowany na x86 by sie nie uruchomil.

Przydatne przelaczniki

--interval 4                  # co ile godzin raportowac (domyslnie 4)
--ca-bundle /sciezka/ca.pem   # wlasne PKI lub certyfikat self-signed
--no-processes                # nie zbieraj listy procesow

Windows

{% if wydanie_windows %}

Wersja obowiazujaca w tej firmie: {{ wydanie_windows.version }} ({{ wydanie_windows.arch }}). Pobierz plik i uruchom go na maszynie docelowej: 

curl.exe -fL -H "Authorization: Bearer TWOJ_TOKEN" `
  -o CMDB-Agent-Setup.exe {{ adres_serwera }}/download/agent-windows.exe

.\CMDB-Agent-Setup.exe

Kreator pyta o adres serwera i token. Do wdrozenia masowego (GPO, Intune, SCCM) instalator przyjmuje -ServerUrl, -Token i -Silent.

{% else %}

Certyfikat serwera

Jesli serwer pracuje na certyfikacie wystawionym przez publiczne urzedy (np. Let's Encrypt), powyzsze polecenia zadzialaja bez zmian.

Przy certyfikacie self-signed maszyna docelowa nie ma powodu mu ufac i pobieranie sie nie powiedzie. Certyfikat trzeba wtedy dostarczyc poza tym kanalem — pobranie go z tego samego serwera, ktoremu jeszcze nie ufamy, niczego nie dowodzi. Skopiuj plik raz, np. przez scp, i wskaz go przy instalacji: 

curl -fsSL --cacert /sciezka/ca.pem {{ adres_serwera }}/download/install.sh \
  | sudo bash -s -- --token TWOJ_TOKEN --ca-bundle /sciezka/ca.pem

Instalator kopiuje certyfikat do /etc/cmdb-agent/ca.pem, wiec plik zrodlowy mozna potem usunac.
